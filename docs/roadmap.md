# 路线图

## 当前：模型汇集与规范登记

- 持续收集眼科基础模型及官方 checkpoint；
- 核验论文、代码、模态、权重访问和许可证；
- 明确已收录、已核验和可运行状态；
- 为团队讨论和 OphAgent 后续选型提供可靠模型资产。

## 近期：选择性接入

- 根据团队确认的评测需求选择模型；
- 逐个核验官方预处理和特征输出接口；
- 逐个实现 Adapter，不追求所有收录模型同时可运行。

## 后续：团队评测与消费

- 使用标准 embedding 开展任务、模态和特征契合度研究；
- OphAgent 按需消费已核验模型信息、Adapter 状态和任务评测产物。

通用大规模 Runner、缓存、断点恢复、多 GPU 和完整训练平台不属于当前阶段。
